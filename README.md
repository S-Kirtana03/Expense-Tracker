# Expense Tracker

A simple multi-page web app to track daily expenses and savings.

I built this project to practice HTML, CSS, and JavaScript.  
The main goal was to create something I can actually use.

## Features

- Add expenses with category, amount, date, and optional note
- Add savings amount with date
- View total expenditure and total savings
- See spending broken down by category
- Simple pie chart showing Expenditure vs Savings

## Pages

- **Home** – Starting page with navigation
- **Expense** – Add and view expenses
- **Savings** – Add savings and see total savings
- **Balance** – View category-wise expenditure and pie chart

## Tech Used

- HTML
- CSS
- JavaScript (Vanilla)
- localStorage (to save data in the browser)

## How to Run

1. Download or clone the repository
2. Open `home.html` in your browser
3. Start adding expenses and savings

No installation or server needed.
